# Brand files

Upload the official Capgemini logo here as **`capgemini-logo-white.svg`**
(the white/reversed version, for dark backgrounds). A PNG works too; if you use
one, update `logo` in `js/stories.js`.

It appears on the intro and final screens, in the top bar, and bottom-right on
every story card, like on the campaign posters. Until the file exists, the
experience hides it.
